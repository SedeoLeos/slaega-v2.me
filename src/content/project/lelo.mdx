# Lelo — Contrôle d'arrivée pour agences de sécurité

## Contexte

Les agences de sécurité doivent s'assurer que leurs agents sont bien présents, à l'heure et au bon poste. Le contrôle manuel est peu fiable ; Lelo le digitalise.

## Ce que j'ai construit

Une application mobile de **contrôle d'arrivée** (pointage) pour les **agences de sécurité** : enregistrement des arrivées des agents et suivi, avec un backend Java pour centraliser les données.

## Stack

Backend **Spring Boot (Java)**, application mobile **Expo (React Native)**.

## Mon rôle

Conception et développement de bout en bout (projet personnel).
