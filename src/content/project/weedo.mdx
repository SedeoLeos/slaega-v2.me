# Weedo — Gestion de prestataires événementiels

## Contexte

Organiser un événement implique de coordonner de nombreux prestataires (traiteurs, lieux, décorateurs, animation...). Weedo centralise cette gestion pour simplifier la mise en relation et le suivi.

## Ce que j'ai construit

Une application de **gestion de prestataires événementiels** : référencement des prestataires, suivi des demandes et coordination autour d'un événement.

## Stack

Application mobile **React Native / Expo**.

## Mon rôle

Développement de l'application, dans le cadre de mes missions chez Nanocreatives.
