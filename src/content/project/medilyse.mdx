# Medilyse — Plateforme web (conception & architecture)

## Contexte

Un produit qui se lance a besoin d'une plateforme claire pour se présenter — et d'une base technique saine pour évoluer sans dette dès le départ.

J'ai mené la **conception complète** de la plateforme web de présentation de Medilyse : **spécifications fonctionnelles**, **architecture**, **modularité** du code et **plan de mise en production**. L'objectif : une base structurée, maintenable et prête à grandir.

## Stack
